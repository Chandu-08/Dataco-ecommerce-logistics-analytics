# Validation results (Kaggle copy, 2026-11-23 analysis)

Python pipeline ran successfully on the original structured CSV (180,519 rows and 53 columns). All 180,519 item IDs are distinct; 65,752 distinct orders; 20,652 distinct customer IDs in the full source. `Customer Id` and `Order Customer Id` match on all rows. No duplicate item IDs, missing order dates, invalid quantities, mismatched gross-minus-discount/net, gross price-times-quantity, or mismatches between the two profit columns were found at 0.02 tolerance. All tested shipping, order, customer and geographic attributes are constant within each order. Item net sales and rolled-up order sales reconcile.

The uploaded order and description CSVs are byte-for-byte identical to the files previously validated. The uploaded access-log CSV has **469,977 rows**, **76 product names**, and a parsed date range of **2017-09-01 to 2018-01-31**. **72 logged product names** match names in the order catalog after trimming and lowercasing. See `clickstream_validation.json`. The logs have no customer/order ID, so product comparisons are not conversion or attribution measures.

Primary filter: 79,107 item rows; 28,965 completed orders; 14,543 completed-order customers. The 28,965 orders have valid noncanceled shipping days; 16,633 are late by day difference. `Delivery Status` agrees with the computed late flag in this population. Verified revenue/profit and KPI details are in `kpi_results.json`; check counts and amounts are in `validation_results.json`.

**Not validated in this environment:** SQL Server connection/import/transformations, Python readback from SQL, Power BI relationships/measures, `.pbix` rendering. The primary SQL Server → Python → Power BI workflow is scripted but must be executed on a SQL Server and Power BI setup. Original currency, order accounting policy, source generating process and causal logistics drivers are not known. All First Class completed orders classify late (4,497 / 4,497), so promises or dataset design may be responsible for this pattern. Month completeness and censoring must be considered for time comparisons.
