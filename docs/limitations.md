# Limitations

This is a historical publicly distributed dataset. The business and process are not independently audited. Sales and recorded profit definitions follow columns and arithmetic but cannot establish collected revenue or accounting margin. Currency is not confirmed. Status inclusion changes totals. Retention is observed within a finite 2015–2018 window; no purchase after snapshot is not proof of churn. Shipping outcomes do not identify carrier, fulfillment center, costs or precise causes. Correlation between discount and profit does not show causality. Clickstream records are page events with IP-like fields but no order/customer/session key; matching product names and comparing same-window sales does not establish unique visitors, conversions or sales attribution. The included HTML report uses aggregate data and is not a `.pbix`; the Power BI file and its execution checks require Power BI Desktop. SQL Server loading and SQL output require a real SQL Server connection. Raw and customer-level CSVs contain sensitive fields or pseudonymous keys and must remain private.
