# Download the source files locally

Place `DataCoSupplyChainDataset.csv`, `DescriptionDataCoSupplyChain.csv`, and `tokenized_access_logs.csv` here. The original dataset is linked and attributed in the project README.

The structured CSV contains customer fields, including a password-like column; the logs contain IP-like fields. Raw files are excluded from the public repository. `data/processed/` contains only publishable aggregate outputs in Git; item, order and customer-level exports stay local.
