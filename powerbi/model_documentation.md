# Power BI build guide

Create a report in Power BI Desktop after running SQL staging, SQL cleaning, SQL facts, SQL clickstream aggregation and Python RFM writeback. Connect to SQL Server database `DataCo_Analytics` and import `analytics.fact_orders`, `analytics.fact_order_items`, `analytics.customer_rfm`, plus optional `analytics.fact_product_views` or `analytics.vw_product_interest` for a separate product-interest visual. Do not import `staging.DataCoRaw` or `staging.DataCoAccessLogs`: these contain personal or IP-like fields. In Power Query, cast IDs to whole number, dates to datetime, amounts to decimal display, flags to true/false; create a date-only column in each fact from `order_date`. Create DimDate covering observed dates and mark it as a date table. Make unique market, region and shipping-mode dimensions from `fact_orders`, plus `dim_customers` from `customer_rfm`; set one-to-many, single-direction relationships. Ensure all fact rows belong to intended dimensions. Relate both facts to DimDate and common market/region dimensions. RFM covers only completed orders. A category slicer affects item measures, while an order can contain multiple categories: use category-specific item charts without implying category order counts add to the grand total. Product interest has a different date range and no customer ID: present it separately rather than connecting page events to orders as conversions.

Paste each measure in `measures.dax` as a separate New measure (the file is a recipe, not a Power BI importable DAX script). Format percentages as percentage with two decimals, currency amounts with the reporting currency unspecified since the dataset lacks a validated currency field. Compare all unfiltered cards with `docs/kpi_results.json` and check slicer totals.

| Page | Cards | Visuals | Slicers |
| --- | --- | --- | --- |
| Executive revenue | Net Sales; Recorded Profit; Profit Margin %; Orders; Average Order Value | Monthly line chart; category bars; market profit bars; margin versus discount table | Date; market; region |
| Customer segments | Customers; Repeat Customer % | Segment counts and recorded sales bars; recency histogram; monthly acquisition cohorts from `cohort_retention.csv` | Date (for orders); market |
| Delivery | Eligible Deliveries; Late Deliveries; Late Delivery %; Late Sales Exposure | Mode rate with counts; region rate with counts; actual versus scheduled days | Date; market; shipping mode |
| Decisions | Late Sales Exposure; Profit Margin %; optional Product Page Events | Market x late-order rate table; segments x late rate; prioritization table with sample sizes; separate product-interest event count versus same-window completed item sales | Market; region; date (only for the measures to which it applies) |

For the cohort heatmap, load `cohort_retention.csv` and use cohort as rows, month_index as columns, retention_rate as values; later cohorts have shorter observation windows. Use color only where data exists. Highlight zero or negative profit in red and show both volume and rate for logistics comparisons. Header: objective, cards: KPI row, visuals: two rows, footer: denominator and eligible status definition. Avoid cross-fact many-to-many relationships or bidirectional filters. Screenshot names are reserved until a `.pbix` is built and visually checked in Power BI Desktop.
